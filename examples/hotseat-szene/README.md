# Beispiel: Hotseat-Szene (zwei Spieler)

Eine kurze Zwei-PC-Szene im Hotseat-Modus (ADR 0020): zwei Spieler, eine
Spielleiter-Session, ein Tisch. Sie zeigt, was das Solo-Beispiel nicht
zeigen kann — Spotlight-Wechsel zwischen benannten Spielern, eine
**Helfen-Probe** nach `system/system.md` § Proben und das `player:`-Feld
im Charakter-Frontmatter.

Gespielt wird mit dem unveränderten Default-System des Templates
(Einfaches 2W6 inklusive Helfen-Regel); die Szene bringt deshalb kein
eigenes `system/` mit. Tischordnung dieser Runde: reihum in
Sitzreihenfolge (Odett, dann Halvar).

Wie im Solo-Beispiel gilt G1 wörtlich: **jeder erzählte Wurf entspricht
1:1 einer Zeile in `journal/rolls.log`**, erzeugt durch echte
Tool-Aufrufe — 3 Wurf-Referenzen in `journal/sessions/session-001.md`,
3 Logzeilen, 0 ohne Gegenstück. Die erzählten Zahlen sind aus dem Log
übernommen, nicht umgekehrt.

> Hinweis: Kanonische Fixture-Quelle der Evals ist ausschließlich
> `examples/mini-campaign/`. Dieses Verzeichnis ist reine Anschauung und
> wird von keinem Checker als Referenz benutzt.
