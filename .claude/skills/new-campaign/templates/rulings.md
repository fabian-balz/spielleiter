# Rulings (append-only)

Akzeptierte improvisierte Regelungen (CLAUDE.md G2). Neue Einträge werden
unten angehängt und nie umgeschrieben; jede Regelung zitiert die Situation,
in der sie entstand.

Format:

```
## R-NNN — <Kurztitel>
- Datum: <ISO>
- Session: <session-NNN oder "außerhalb">
- Situation: <was war ungeregelt>
- Regelung: <die akzeptierte Regel>
```
